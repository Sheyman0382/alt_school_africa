FAQs

How does URL shortening work?

URL shortening converts a long web address into a shorter link that redirects visitors to the original destination.

Is it necessary to create an account to use the URL shortening service?

You can create short links with the free plan. An account helps you manage and track your links.

Are the shortened links permanent? Will they expire?

Links remain available according to the service's link-retention policy and your plan.

Are there any limitations on the number of URLs I can shorten?

Limits depend on the plan you choose.

Can I customize the shortened URLs to reflect my brand or content?

Yes. Custom aliases and branded domains can make links easier to recognize.

Can I track the performance of my shortened URLs?

Analytics can show useful information such as clicks and engagement.

How secure is the URL shortening service? Are the shortened links protected against spam or malicious activity?

Security features and link checks help protect users. Always verify unfamiliar links before opening them.

What is a QR code and can I use it?

A QR code is a scannable image that can open a web address on a compatible device.

Is there an API available for integrating the URL shortening service into my own applications or workflows?

API access is available with eligible plans.
